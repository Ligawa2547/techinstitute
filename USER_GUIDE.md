# Ratego Institute - User Guide

## For Students

### Dashboard Navigation
Your dashboard now includes these sections:

#### 📅 Calendar
- View all upcoming live classes and important deadlines
- Navigate between months using Previous/Next buttons
- Click on events to see details
- Upcoming events appear in the right sidebar
- Join live classes directly from the calendar

#### 🎥 Live Lessons
- See all live classes you're enrolled in
- Three filter options:
  - **Upcoming**: Classes that haven't started yet
  - **Past**: Completed sessions
  - **All**: All classes
- Status badges help you know class status:
  - **Live Now** (red, animated): Class is currently happening
  - **Starting Soon** (yellow): Less than 60 minutes away
  - **Upcoming** (blue): Future classes
  - **Ended** (gray): Completed sessions
- Click "Join Live Class" button to access the meeting
- View class descriptions and timing

#### 🔔 Notifications
- All alerts and messages in one place
- Filter options:
  - **Unread**: New notifications you haven't seen
  - **All**: Complete notification history
- Mark notifications as read individually or all at once
- Delete old notifications to clean up
- Color-coded notification types:
  - Blue: General information
  - Green: Success messages
  - Yellow: Warnings
  - Red: Important alerts

#### 📈 My Progress
- Track your learning journey
- **Overall Stats** show:
  - Your overall progress percentage
  - How many programs you're active in
  - How many programs you've completed
- **Program Details**:
  - Select different programs from the left list
  - See your completion percentage with progress bar
  - View lessons completed vs total
  - Check when you last accessed the program
  - See completion badge when you finish
- **Lesson Breakdown**:
  - Checkmarks show completed lessons
  - Empty circles show pending lessons
  - Click to track individual progress

### Using Google Login
1. Click "Sign in with Google" on the login page
2. Choose your Google account
3. You'll be automatically logged in
4. If enrolling in a program, you'll be redirected to that program

## For Administrators

### Admin Dashboard Navigation
Your admin panel now includes:

#### 📅 Calendar Management
- **View Events**: See all scheduled events across all programs
- **Create Event**: Click "Create Event" button to schedule new items
- **Manage Events**: 
  - Edit event details
  - Delete events you no longer need
- **Navigation**: Use Previous/Next to view different months
- All events shown in timeline view with times and locations

#### 🔔 Notifications
- **Send Notification**:
  1. Click "Send Notification" button
  2. Select a student from the dropdown
  3. Choose notification type (Info, Success, Warning, Error)
  4. Write title and message
  5. Click "Send Notification"
- **View History**: See all notifications you've sent
- **Delete**: Remove old notifications from history
- **Color Coding**: Each type has distinct color for quick scanning

#### 📊 Progress Analytics
- **Key Metrics**:
  - Total students enrolled across all programs
  - How many have completed their courses
  - Overall completion rate as a percentage
  - Average progress of all students
- **Program Overview**:
  - Each program listed with statistics
  - See total students per program
  - Track completions and in-progress counts
  - Visual progress bars show average progress
- **Top Performers**:
  - See which students are progressing fastest
  - Shows their completion % and lessons done
  - Helps identify students who might need support

### Best Practices

#### Student Communication
- Use **Success** notifications for course completion announcements
- Use **Warning** for upcoming deadlines
- Use **Error** for urgent issues
- Use **Info** for general updates

#### Scheduling Classes
- Schedule live classes at least 24 hours in advance
- Include time zone information in class descriptions
- Add Google Meet link in location field
- Consider time zones of your global student base

#### Tracking Progress
- Check analytics weekly to identify struggling students
- Reach out to students with low progress
- Celebrate milestone completions
- Use data to improve course content

#### Notifications
- Send weekly progress updates to active students
- Announce new content or schedule changes promptly
- Notify students of important deadlines
- Acknowledge completed courses with congratulations

## Common Tasks

### How to View My Classes (Student)
1. Go to Dashboard
2. Click "Live Lessons" in sidebar
3. See your upcoming classes
4. Click "Join Live Class" when it shows "Live Now"

### How to Track Student Progress (Admin)
1. Go to Admin Panel
2. Click "Progress" in sidebar
3. View overall completion rates
4. See individual student performance in "Top Performers"
5. Check which students need help

### How to Send an Update (Admin)
1. Go to Admin Panel
2. Click "Notifications" in sidebar
3. Click "Send Notification"
4. Select student or broadcast message
5. Write message and send

### How to Schedule an Event (Admin)
1. Go to Admin Panel
2. Click "Calendar" in sidebar
3. Click "Create Event" button
4. Fill in event details (title, time, location/link)
5. Save and it appears on calendar immediately

## Troubleshooting

### I Can't See My Classes
- Check that you're enrolled in the program
- Verify the enrollment status is "Active"
- Contact admin if classes aren't showing

### Live Lesson Won't Join
- Make sure the class has started (within 2 hours)
- Check that your browser allows popups
- Verify your internet connection
- Try refreshing the page

### Notifications Not Updating
- Refresh the notifications page
- Check that you're connected to the internet
- Try logging out and back in

### Progress Not Showing
- Complete at least one lesson first
- Wait a few moments for data to sync
- Refresh the progress page
- Contact support if still not working
